# Skill: PR Merge Specialist

## Purpose
Deterministic PR remediation and queue management.

## Key Subsystems
- **Grand Orchestrator**: Real-time TUI dashboard and Auto-Pilot.
- **Predictive Queue Scorer**: WSEMT-based risk-adjusted prioritization.
- **Feedback Engine**: Ingestion and classification.
- **Verification Engine**: Local command mapping and execution.
- **Body Engine**: Checklist enforcement.
- **Reply Engine**: Guarded thread resolution via GraphQL.

## Constraints
- **Throughput over Latency**: Optimize global repository velocity.
- **DAG Dependency Awareness**: Process stacks in topological order.
- **Semantic Safety**: Escalation for high-risk architectural divergence.
- Ambiguity = Human Escalation.
- High-Risk Conflict = No Auto-Resolution.
- No Evidence = No Mutation.
