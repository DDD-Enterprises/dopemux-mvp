## Contract decisions

A trusted local operator/Master explicitly admits an exact mandate under an authorization reference.
Local filesystem ownership is the trust boundary; this is not a multi-user API, signature verifier or grant issuer.
Mandates include implementation, tests and prospectively declared repair/retest branches under one original
scope, active/wall/spend envelope. No command/read/metadata microgrants or routine browser relays.
Technical dependencies may consume same-project/same-mandate successful completion; final native acceptance is separate.

The first real adapter executes operator-admitted argv only, no shell, with replacement private environment,
bounded raw stdout/stderr, timeout, owned process-group TERM/KILL/drain and explicit native exit/closure.
Only local zero-paid-cost commands are supported now. Model CLI dispatch is not silently inferred.
Sol-first model policy persists; Fable is pinned to Claude Code through
ANTHROPIC_BASE_URL=http://127.0.0.1:47821 when an actual separately qualified model adapter is used.
No bypass flags, VM, credential or global security changes. Declared filesystem scope is monitored;
this process runner does not claim an OS sandbox or network cash meter.

One coordinator holds an exclusive journal lock. Restart marks in-flight intent EFFECT_UNKNOWN and never
requeues it. READY work can continue; completed stages and saved return bytes are reused.
Master-side receiver writes an immutable digest-bound delivery ACK. Delivery is not native acceptance,
readiness, merge or release. No self-authored acceptance is inferred.
