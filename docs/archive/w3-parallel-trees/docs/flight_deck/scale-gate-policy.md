# Scale Gate Policy

## Overview

The scale gate provides advisory decisions to guide operator posture changes.
All decisions are **READ-ONLY advisory**.  No code changes posture automatically.
Operator action is required for every posture change.

---

## Six-Decision Taxonomy

### 1. `CONTINUE_SUPERVISED`

**Condition**: compliance ≥ 1.0, incidents = 0, acceptance ≥ 0.75, no HIGH-risk failures.

**Meaning**: Current supervised posture is healthy. Continue as-is.

**Operator action**: No change required.

---

### 2. `PAUSE_AND_REVIEW`

**Condition**: `signoff_compliance_rate < 1.0` in last window (any compliance gap).

**Meaning**: One or more mutation-class actions occurred without a matching operator signoff.
Operations should pause until the gap is understood and resolved.

**Operator action**: Review signoff log, identify unsigned cases, log retroactive signoffs or
adjust process to ensure signoffs are captured before mutation-class actions execute.

---

### 3. `RESTRICT_ACTION_SET`

**Condition**: `incident_rate > 0.05` (more than 5% of safety events are non-LOW-risk
and non-FAILED).

**Condition is auto-applied**: when triggered, the decision is set immediately;
no human pre-approval is needed to generate this advisory.

**Meaning**: Incident frequency is elevated. Reduce the scope of autonomous actions.

**Operator action**: Disable auto-apply for HIGH and MEDIUM risk classes until
incident rate returns below threshold.

---

### 4. `DISABLE_AUTO_APPLY`

**Condition**: Any HIGH-risk auto-apply failure detected in the rolling window
(`high_risk_failures > 0`).

**Meaning**: A HIGH-risk automatic action has failed. Auto-apply must be disabled
until root cause is identified and mitigated.

**Operator action**: Disable auto-apply globally. Investigate the failed action.
Re-enable only after a formal review cycle.

---

### 5. `ROLLBACK_TO_EVALUATION_ONLY`

**Condition**: `incidents ≥ 2` OR `acceptance_rate < 0.5`.

**Meaning**: Critical degradation. The system should revert to evaluation-only mode
where no actions are taken autonomously.

**Operator action**: Immediately disable all autonomous actions. Conduct a formal
incident review. Schedule a go/no-go review before resuming.

---

### 6. `EVALUATE_CAUTIOUS_EXPANSION`

**Condition**: `acceptance_rate ≥ 0.9` AND `compliance_rate == 1.0` AND `actual_cases ≥ 20`.

**Meaning**: Metrics support considering a cautious expansion of the autonomous action scope.

**Operator action**: Review the full rolling window. If appropriate, propose a scope
expansion in the next formal review cycle. Do not expand scope unilaterally.

---

## Governance Invariants

1. `posture_change_authorized` is always `False` in all generated decisions.
2. Decisions are `advisory_only: true`.
3. The note field always states: "No code changes posture automatically. Operator action required."
4. Scale-gate decisions are generated by `FlightDeckOpsEngine.generate_scale_gate_decision()`.
5. Decisions are generated from combined health data: rolling health + compliance + incident trends + auto-apply safety.
