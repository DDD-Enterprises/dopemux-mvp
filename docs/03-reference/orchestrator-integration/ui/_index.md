# UI Dashboard & Cockpit Integration

The orchestrator daily planning and tracking data is surfaced dynamically through CLI-rendered TUIs and dashboard frames.

## Dashboard Panels
1.  **Context Freshness Panel**: Summarizes cache status.
2.  **Unblocked Queue Panel**: Lists next high-leverage packets.
3.  **PR Readiness Grid**: Inspects checks, age, and proofs.
