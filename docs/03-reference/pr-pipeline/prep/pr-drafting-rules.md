# PR Drafting Rules

Superseded by [`operator-contract.md`](./operator-contract.md) §5
(S4 - Draft or verify PR metadata).

This file previously defined a `CREATE_READY` / `DRAFT_RECOMMENDED` /
`BLOCKED_*` posture-recommendation vocabulary emitted by the draft engine.
That vocabulary is retired; the canonical minimum PR body (objective, Task
Packet, scope, risk lane, validation actually run, audit status, proof
status, blockers, rollback, explicit operator gates) and the `DRAFT_ONLY`
default posture in §5 S4 are the current authority. The evidence-backed,
no-fictional-verification discipline this file described for PR body
content remains sound practice but is non-normative here; it does not
grant any creation authority beyond §5 S4.

This stub is kept only so existing links into this filename keep resolving.
