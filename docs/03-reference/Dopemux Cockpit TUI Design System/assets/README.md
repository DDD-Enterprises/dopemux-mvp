# Assets

This system has no image assets. The cockpit is text-only.

What lives here:
- `glyphs.md` — visual glyph contract, wordmark rules, and optional Nerd Font icon table
- `frame_chars.md` — box-drawing characters used by the static frame
- `brand_mark.txt` — the stylized wordmark `DØPΞM∪X` and plain fallback `DOPEMUX`

Do not add SVGs, PNGs, or other raster/vector icons. The TUI contract
forbids them.
