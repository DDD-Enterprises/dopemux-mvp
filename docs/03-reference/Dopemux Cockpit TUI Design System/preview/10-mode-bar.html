Active mode marked with *. Numbers are direct keybinds. No mouse. No hover. The "selected" affordance is the asterisk + cyan color, not background fill.

Chrome doctrine: Mode selection is chrome, not data provenance. The mode bar's declared authority is dopemux; its function is operator control surface. Mode-bar rows do not carry SRC. PM and Implementer modes do not own PM truth — child panes declare actual authority (e.g. repo-truth-extractor, task-orchestrator, ConPort, Leantime).
