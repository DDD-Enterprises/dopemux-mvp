Closed chip set: LIVE | BLOCKER | OVERRIDE | LOGGED | AFTERCARE | EDGE. Chips are bracketed literals; removing color does not destroy meaning. Chips are render/category markers — they are not the complete status vocabulary. Explicit status words may still appear in copy/body text: queued, running, complete, blocked, failed, degraded, unknown, copy refed, needs verification.

UNKNOWN doctrine: UNKNOWN remains literal text in affected fields. UNKNOWN is never a chip. UNKNOWN is never collapsed into EDGE. EDGE is only for edge / experimental / uncertain category presentation where appropriate.

Web aliases map (chip-only): DEGRADED->OVERRIDE, FAILED->BLOCKER, BLOCKED->BLOCKER, SYNC->AFTERCARE.
