Status language · operator-grade labels
queued · run placed; not started
running · run or phase is executing
complete · all phases verified; artifacts written
blocked · gate refused operation; remediation required
failed · run terminated with error; see failure index
degraded · running with reduced provider/route capacity
health failed · readiness check refused launch
preflight blocked · provider/route preflight refused launch
needs verification · artifacts require operator gate
coverage incomplete · rollup shows uncovered domains
stale copy ref baseline · baseline older than threshold
copy refed · proof bundle emitted; run is closed
These labels are explicit, distinct, and never euphemistic. They map to chips at render time but stand alone in copy.
