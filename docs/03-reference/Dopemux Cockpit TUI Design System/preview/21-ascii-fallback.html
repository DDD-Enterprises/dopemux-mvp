Glyphs are loaded from the Nerd Font codepoint range. _FALLBACK in src/dopemux/ui/theme.py::Glyphs declares the ASCII substitute. ASCII is the only acceptable substitute — no emoji, no Lucide, no SVG icon library. Frame characters never substitute to ASCII unless the renderer cannot draw box-drawing at all (e.g. dumb pipe).
Forbidden arrows: → ⇒ ➜. Use -> when directionality is required.
