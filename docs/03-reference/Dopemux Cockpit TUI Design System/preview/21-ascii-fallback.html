Rich glyphs may be loaded from Dopemux Term Nerd Font. _FALLBACK in src/dopemux/ui/theme.py::Glyphs declares the ASCII substitute. ASCII is the only acceptable substitute — no emoji, no Lucide, no SVG icon library. Frame characters never substitute to ASCII unless the renderer cannot draw box-drawing at all (e.g. dumb pipe). Nerd Font glyphs are rich-mode enhancements only; they are not the canonical brand mono and must never be the only signal. The stylized wordmark never replaces domain, authority, role, next_action, SRC, status, or result.
Unicode arrows and Unicode ellipsis are forbidden. Use -> when directionality is required.
