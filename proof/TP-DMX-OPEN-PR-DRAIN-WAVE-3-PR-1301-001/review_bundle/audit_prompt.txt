Independent embedded audit for DDD-Enterprises/dopemux-mvp PR #1301, part of a
governed PR-drain packet (TP-DMX-OPEN-PR-DRAIN-MERGE-001, Wave 3). This PR
modifies scripts/governance/validate_change_contract.py, a security-relevant
validator that decides which file paths count as a "proof-only" delta (used
to decide whether a signed audit attestation can be reused without
re-auditing, and to gate what may land on top of an already-audited commit).

THE CHANGE: it widens the packet-root proof-only allow-list regex from
matching only `proof/<packet-id>/<known-artifact-pattern>` to also match
`proof/<packet-id>/implementation-notes.md` as a literal, single-segment
filename directly under the packet directory. Critically, this same widening
was NOT applied to the separate `proof/pr_merge/embedded-audit/pr-<N>/`
branch of the regex, which stays restricted to the original artifact
pattern only.
