    feat(ui): add soft confirmation for skip task action
    
    This change implements a two-step confirmation pattern for the "Skip" action in the TaskSequencer component. Users now need to click the Skip button twice within a 3-second window to confirm a skip, preventing impulsive or accidental sequence jumps.
    
    Key improvements:
    - Added `isSkipConfirming` state with a 3-second auto-reset.
    - Swapped Skip icon to `AlertTriangle` and updated label to "Confirm Skip?" during the pending state.
    - Added `skip-pulse` animation for visual reinforcement during confirmation.
    - Updated `aria-label` to be context-aware (Confirm skip vs Skip to [Task]).
    - Fixed a pre-existing ARIA role violation in `PredictionPanel.tsx` tests during loading state.
    - Verified with accessibility tests and manual frontend verification.
    
    ♿ Accessibility: Ensures non-reversible sequence jumps have clear confirmation and descriptive ARIA labels.
