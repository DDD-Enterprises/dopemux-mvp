# 01 Entity and State Model

## Core PM Entities Owned by This Repo
- `Project` records are persisted in `zp_projects` with state-bearing fields including `state`, `type`, `parent`, `psettings`, `start`, `end`, and `sortIndex` (`app/Domain/Install/Services/SchemaBuilder.php:325`, `app/Domain/Install/Services/SchemaBuilder.php:330`, `app/Domain/Install/Services/SchemaBuilder.php:335`, `app/Domain/Install/Services/SchemaBuilder.php:337`, `app/Domain/Install/Services/SchemaBuilder.php:338`, `app/Domain/Install/Services/SchemaBuilder.php:344`).
- `Ticket`/`Milestone`/`Subtask` records are persisted in `zp_tickets` with workflow-relevant fields `status`, `type`, `dependingTicketId`, `milestoneid`, `sprint`, `sortindex`, `kanbanSortIndex`, and scheduling fields (`app/Domain/Install/Services/SchemaBuilder.php:426`, `app/Domain/Install/Services/SchemaBuilder.php:435`, `app/Domain/Install/Services/SchemaBuilder.php:443`, `app/Domain/Install/Services/SchemaBuilder.php:453`, `app/Domain/Install/Services/SchemaBuilder.php:457`, `app/Domain/Install/Services/SchemaBuilder.php:454`, `app/Domain/Install/Services/SchemaBuilder.php:455`).
- `Sprint` records are persisted in `zp_sprints` with `projectId`, `startDate`, `endDate` (`app/Domain/Install/Services/SchemaBuilder.php:558`, `app/Domain/Install/Services/SchemaBuilder.php:560`, `app/Domain/Install/Services/SchemaBuilder.php:562`, `app/Domain/Install/Services/SchemaBuilder.php:563`).
- `Timesheet` records are persisted in `zp_timesheets` with `ticketId`, `workDate`, `hours`, and billing/payment state (`invoicedEmpl`, `invoicedComp`, `paid`) (`app/Domain/Install/Services/SchemaBuilder.php:485`, `app/Domain/Install/Services/SchemaBuilder.php:488`, `app/Domain/Install/Services/SchemaBuilder.php:489`, `app/Domain/Install/Services/SchemaBuilder.php:490`, `app/Domain/Install/Services/SchemaBuilder.php:493`, `app/Domain/Install/Services/SchemaBuilder.php:494`, `app/Domain/Install/Services/SchemaBuilder.php:498`).
- `Comments` are persisted in `zp_comment` and include optional `status` plus module/entity binding (`module`, `moduleId`) (`app/Domain/Install/Services/SchemaBuilder.php:251`, `app/Domain/Install/Services/SchemaBuilder.php:253`, `app/Domain/Install/Services/SchemaBuilder.php:257`, `app/Domain/Install/Services/SchemaBuilder.php:259`).
- `Ticket history` is persisted in `zp_tickethistory` using `changeType` + `changeValue` snapshots (`app/Domain/Install/Services/SchemaBuilder.php:409`, `app/Domain/Install/Services/SchemaBuilder.php:413`, `app/Domain/Install/Services/SchemaBuilder.php:414`).
- `Audit` events are persisted in `zp_audit` with `action`, `entity`, `entityId`, and serialized `values` (`app/Domain/Install/Services/SchemaBuilder.php:630`, `app/Domain/Install/Services/SchemaBuilder.php:634`, `app/Domain/Install/Services/SchemaBuilder.php:635`, `app/Domain/Install/Services/SchemaBuilder.php:636`, `app/Domain/Install/Services/SchemaBuilder.php:637`).
- `Entity relationships` are persisted in `zp_entity_relationship` as polymorphic links (`entityA`, `entityAType`, `entityB`, `entityBType`, `relationship`) (`app/Domain/Install/Services/SchemaBuilder.php:713`, `app/Domain/Install/Services/SchemaBuilder.php:716`, `app/Domain/Install/Services/SchemaBuilder.php:717`, `app/Domain/Install/Services/SchemaBuilder.php:718`, `app/Domain/Install/Services/SchemaBuilder.php:719`).

## State Taxonomies and Labels
- Ticket status taxonomy is seeded in code (`NEW`, `INPROGRESS`, `DONE`) with default IDs including blocked/waiting/done/archived (`app/Domain/Tickets/Repositories/Tickets.php:32`, `app/Domain/Tickets/Repositories/Tickets.php:41`, `app/Domain/Tickets/Repositories/Tickets.php:55`, `app/Domain/Tickets/Repositories/Tickets.php:62`, `app/Domain/Tickets/Repositories/Tickets.php:69`).
- Ticket status labels are per-project mutable via settings key `projectsettings.{project}.ticketlabels` and can be saved through service logic (`app/Domain/Tickets/Repositories/Tickets.php:130`, `app/Domain/Tickets/Repositories/Tickets.php:132`, `app/Domain/Tickets/Services/Tickets.php:130`, `app/Domain/Tickets/Services/Tickets.php:149`, `app/Domain/Tickets/Services/Tickets.php:151`).
- Project state has a local map (`0 => OPEN`, `1 => CLOSED`) but query usage also treats `-1` as closed/open boundary (`app/Domain/Projects/Repositories/Projects.php:33`, `app/Domain/Projects/Repositories/Projects.php:423`, `app/Domain/Projects/Repositories/Projects.php:427`).

## Relationship Model
- User-to-project membership/authorization is stored in `zp_relationuserproject` and used for access checks (`app/Domain/Install/Services/SchemaBuilder.php:391`, `app/Domain/Projects/Repositories/Projects.php:898`, `app/Domain/Projects/Repositories/Projects.php:901`).
- Ticket dependency/parenting is represented by `dependingTicketId`; milestone membership by `milestoneid`; sprint membership by `sprint` (`app/Domain/Install/Services/SchemaBuilder.php:443`, `app/Domain/Install/Services/SchemaBuilder.php:457`, `app/Domain/Install/Services/SchemaBuilder.php:453`).
- Collaborators are represented in `zp_entity_relationship` with `relationship='collaborator'` (`app/Core/Support/EntityRelationshipEnum.php:15`, `app/Domain/Tickets/Repositories/Tickets.php:1718`, `app/Domain/Tickets/Repositories/Tickets.php:1722`, `app/Domain/Tickets/Repositories/Tickets.php:1728`).

## Persistence Writers and Readers
- Ticket writes occur through repository `addTicket`, `updateTicket`, `patchTicket`, `updateTicketStatus` (`app/Domain/Tickets/Repositories/Tickets.php:1422`, `app/Domain/Tickets/Repositories/Tickets.php:1488`, `app/Domain/Tickets/Repositories/Tickets.php:1462`, `app/Domain/Tickets/Repositories/Tickets.php:1525`).
- Project writes occur through repository `addProject`, `editProject`, `patch`, and deletion (`app/Domain/Projects/Repositories/Projects.php:699`, `app/Domain/Projects/Repositories/Projects.php:747`, `app/Domain/Projects/Repositories/Projects.php:1010`, `app/Domain/Projects/Repositories/Projects.php:807`).
- Sprint writes occur through `addSprint`, `editSprint`, `delSprint` (`app/Domain/Sprints/Repositories/Sprints.php:191`, `app/Domain/Sprints/Repositories/Sprints.php:204`, `app/Domain/Sprints/Repositories/Sprints.php:217`).
- Timesheet writes occur through upsert/add/update/invoice mutation methods (`app/Domain/Timesheets/Repositories/Timesheets.php:584`, `app/Domain/Timesheets/Repositories/Timesheets.php:738`, `app/Domain/Timesheets/Repositories/Timesheets.php:797`, `app/Domain/Timesheets/Repositories/Timesheets.php:871`).
- Comments are written by `addComment`, `editComment`, `deleteComment` in repo/service path (`app/Domain/Comments/Repositories/Comments.php:108`, `app/Domain/Comments/Repositories/Comments.php:130`, `app/Domain/Comments/Repositories/Comments.php:123`, `app/Domain/Comments/Services/Comments.php:45`).
