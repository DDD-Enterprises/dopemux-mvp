# Task Packet: TP-DMX-GPTR-TWO-PHASE-RUNNER-001 · Tooling · GPT Researcher Two-Phase Runner

## Objective

Add a small local wrapper for GPT Researcher that uses a concise web research query first and injects local evidence only during report synthesis.

## Scope

IN:

* Add a script under `scripts/gpt-researcher/`.
* Add focused unit tests under `tests/scripts/`.
* Document the runner in the script help and task packet.

OUT:

* No changes to Docker images, MCP server code, or provider credentials.
* No live GPT Researcher/provider run in tests.
* No mutation of generated research artifacts or reports.

## Invariants (Must Remain True)

* Local evidence must not be sent as the initial Tavily/search query.
* Secret values must not be captured in metadata or prompts.
* Repo-tracked outputs must not be generated by default.
* The primary checkout dirty state remains untouched.

If an invariant appears impossible, stop and report.

## Plan (Numbered)

1. Add tests for concise-query validation, evidence prompt construction, dry-run output, and secret-presence metadata.
1. Implement the minimal runner needed to pass those tests.
1. Run targeted tests, compile check, `git diff --check`, and inspect scope.
