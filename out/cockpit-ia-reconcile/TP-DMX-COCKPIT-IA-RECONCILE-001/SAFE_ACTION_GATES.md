# Safe Action Gates

| Gate | Class | Required confirmation | Required proof | TP/governance gate | Blocked behavior | Audit logging expectation | Suggested UI language |
| --- | --- | --- | --- | --- | --- | --- | --- |
| read-only inspect | DISPLAY_ONLY or INSPECT_ACTION | None for display; explicit invoke for inspect. | Source authority and timestamp/result. | No TP gate unless inspecting protected data. | No mutation. If side effects are discovered, reclassify. | Log inspect command path and result summary. | Inspect only. No writes. |
| generated artifact | GENERATED_ARTIFACT | Confirm output path and overwrite behavior. | Artifact path plus checksum or summary. | TP gate when artifact is contractual evidence. | Block if output path or writer authority is unknown. | Log command, cwd, output path, checksum. | Generate artifact after confirmation. |
| config mutation | CONFIG_MUTATION | Confirm target file/service and before/after diff where possible. | Config diff or post-action status. | Admin/governance gate for routing, hooks, profiles, env. | Block if target cannot be resolved or rollback path is absent. | Log target, diff summary, command path, exit code. | Admin change requires confirmation. |
| write local | WRITE_LOCAL | Confirm path and side effect. | Filesystem diff, artifact path, or exit code. | TP gate when writing proof/task artifacts. | Block destructive local writes unless policy allows. | Log path, action, result. | Local write requires confirmation. |
| write remote | WRITE_REMOTE | Confirm remote target and account/context. | Remote receipt or API result. | Governance gate required. | Block by default until remote mutation policy exists. | Log remote target, actor, receipt. | Remote write blocked unless governed. |
| start/stop service | START_STOP_SERVICE | Confirm service, scope, and expected state transition. | Post-action status/log evidence. | Admin/runtime gate. | Block if service authority or cwd is ambiguous. | Log service, before/after status, exit code. | Service state change requires confirmation. |
| execution handoff | EXECUTION_HANDOFF | Confirm TP/task id, runner, cwd, branch, and output/proof target. | Exit code, proof path, validation summary. | TP/governance gate required. | Block if TP/proof target is absent for governed execution. | Log runner, args, cwd, branch, proof. | Execution handoff requires TP/proof gate. |
| destructive/blocklisted action | BLOCKED_IN_COCKPIT | No executable confirmation. | Block reason and external workflow only. | External governance only. | Always blocked in Cockpit. | Log attempted selection as blocked. | Blocked in Cockpit. |
| unknown action | UNKNOWN | No executable confirmation. | Investigation requirement. | Investigation packet required before reclassification. | Always blocked until classified. | Log unknown row view/selection only. | Unknown action. Classification required. |
