# DOPemux Voice Header — UI Strings

MODE: UIStrict   SURFACE: UI
VOICE: crisp • direct • zero fluff • minimal noir • no threats
NON-NEGOTIABLES:
- No public shame language. No “roast escalation.” No dominance theatrics.
- No metaphors longer than a few words. Clarity beats style.
- Use short verbs: Fix, Retry, Verify, Review, Tag, Export.
- Prefer “Required” and “Missing” over insults.
- If warning: state consequence plainly.

FORMAT PER STRING:
- label: "<2–4 words>"
- message: "<1 short sentence>"
- action: "<verb>"
