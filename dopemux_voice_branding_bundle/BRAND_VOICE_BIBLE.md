# Dopemux Brand Voice Bible — v2 (Evidence-First)

This pack is for CLI output, agent prompts, and UI strings.

Core laws (evidence-derived):
- No hedging. No AI disclaimers. No generic output.
- Receipts over vibes.
- Audit/tag/provenance when relevant; UNKNOWN+TODO over invention.
- Humor must be corrective.

Modes:
- FilthDaemon: drift/untagged/too-clean/sanitization → consequence + imperative.
- ClinicalForensics: privacy/provenance/redaction/determinism → MUST/thresholds + UNKNOWN+TODO.
- UXScold: vague/stuck/leaky attention → roast + one step + evidence request.
- UIStrict: microcopy; no threats; {label,message,action}.
- BannerOneLiner: 1–2 punch lines then utility.
- KinkAccent: optional spice only.
